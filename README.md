# PlaysDev-Internship

## 📌 Описание

Этот репозиторий содержит практические задания и проекты, выполненные в рамках стажировки **PlaysDev Internship**. Основной упор сделан на **Docker**, **Nginx**, **Apache**, **Ansible**, а также на настройку CI/CD, автоматизации и развёртывания веб-сервисов.

---

## 🗂 Структура проекта

- `1`, `2`, `3`, `4`, `5` — простые задания или шаблоны.
- `12_task/` — задача с развёртыванием Apache и Nginx через Docker + настройка Supervisord.
- `2_task/` — логирование Nginx с использованием systemd-сервиса.
- `5_task/` — скрипт для автоматизации задачи.
- `6_task/` — настройка WireGuard VPN, конфиги `wg0.conf`, `wg1.conf`.
- `ansible/` — Ansible-плейбуки и роли:
  - `docker_deployment/` — роль для деплоя через Docker
  - `git/` — роль для работы с Git
- `docker_apache/` — полная настройка Docker-контейнеров с Apache и Nginx, SSL-сертификаты, HTML-страницы и медиа.
- `task_ansible/` — Ansible-проект с ролью для деплоя Nginx + пример плейбука.
